Dette dokument hjælper fremtidige Claude sessions med at forstå projektet og workflow.

## Projekt Oversigt

- **Sprog:** Dansk
- **Tech:** Kun HTML + CSS (ingen JavaScript)
- **Fokus:** Sikkerhed, tilgængelighed, responsivt design
- **Live site:** https://rgehrkedk.github.io/html-templates/

## Git Workflow - VIGTIGT! 🚨

### Auto-Merge System
Dette projekt har **automatisk merge til main** via GitHub Actions:

1. **Du arbejder på:** `claude/[task]-[session-id]` branches
2. **Du pusher til:** Din `claude/*` branch
3. **GitHub Actions:** Merger automatisk til `main`
4. **GitHub Pages:** Deployer automatisk fra `main`

### Workflow fil
`.github/workflows/auto-merge-to-main.yml` - Konfigureret til at merge alle `claude/**` branches.

### Hvad betyder det?

✅ **Du skal:**
- Arbejde på `claude/*` branches (som normalt)
- Pushe til din `claude/*` branch
- Lade GitHub Actions gøre resten

❌ **Du skal IKKE:**
- Prøve at pushe direkte til `main` (giver 403 fejl)
- Manuelt merge branches
- Bekymre dig om deployment

## Design Principper

### Apple-variant (insurance-annual-letter-apple.html)
Efter flere iterationer er vi landet på:

- **Minimalistisk:** Ingen gradient-effekter, solid farver
- **Kompakt:** Lille padding (24px), tætte gaps (12px)
- **Typografi:** Klar hierarki (48px → 28px → 21px → 17px → 11-13px)
- **Glassmorphism:** Simpel `backdrop-filter: blur(20px)`
- **Farver:** `#1d1d1f` (primær), `#424245` (sekundær)
- **WCAG AA:** Alle kontraster overholder tilgængelighedskrav
- **Dark mode:** Fuld support via `prefers-color-scheme`

### Design Fejl at Undgå
Brugeren ønskede IKKE:
- ❌ Gradient text effects
- ❌ Radial overlays og fancy pseudo-elements
- ❌ For meget padding/spacing
- ❌ Dårligt typografisk hierarki
- ❌ Emojis som ikoner (brug CSS shapes)

## Vigtige Kommandoer

### Arbejde med branches
```bash
# Opret ny branch (auto-genereret session ID)
git checkout -b claude/new-feature-[session-id]

# Commit og push
git add .
git commit -m "Beskrivelse"
git push -u origin claude/new-feature-[session-id]

# GitHub Actions merger automatisk til main!
```

### Lokal test
Åbn `index.html` eller templates direkte i browser - ingen build step nødvendig.

5. **Ingen JS:** Projektet er kun HTML + CSS
