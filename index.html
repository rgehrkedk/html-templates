HTML Templates til e-Boks

Responsive HTML/CSS skabeloner til digitale beskeder

Oversigt

Dette repository indeholder en samling af HTML/CSS skabeloner designet til e-Boks webview beskeder. Hver skabelon er bygget med:

  • Sikkerhed i fokus: Ren, valideret HTML uden eksterne afhængigheder
  • Responsivt design: Mobilvenlige layouts der virker på alle enheder
  • Nem tilpasning: Velstruktureret kode til hurtige ændringer
  • Ingen JavaScript: Kun HTML og CSS for maksimal kompatibilitet
